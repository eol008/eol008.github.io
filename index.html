Bosch Rexroth

In the spring and summer of 2025, I Co-op'd for the Fountain Inn location of Bosch Rexroth. In this time I gained lots of experience with integrating with different SDK's, SQL database querying/setup, developing API endpoints, using SignalR for socket connections between a web and desktop app, and the deployment process of software onto an active work environment.
